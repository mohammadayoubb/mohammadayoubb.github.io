    SoukPilot AI

    An operations copilot for Lebanese small businesses. It reads paper supplier invoices, WhatsApp orders and stock records, turns them into a live inventory, and answers questions about the business by text or voice.

    A customer's WhatsApp message

    Bddi 2 Pepsi w 1 chips, delivery Hamra, cash

    LLM extraction, then Pydantic validation
    {
  "intent": "new_order",
  "items": [
    { "product": "Pepsi", "quantity": 2 },
    { "product": "Chips", "quantity": 1 }
  ],
  "delivery_area": "Hamra",
  "payment_method": "cash_on_delivery"
}

    How an invoice becomes stock

    1. Invoice photoimage or PDF
    2. Vision OCROpenAI Vision
    3. GPT-4o-ministructured JSON
    4. Pydanticreject bad rows
    5. InventoryPostgreSQL, per tenant

    Hybrid RAG

    BM25 keyword scoring fused with ChromaDB vector search through Reciprocal Rank Fusion over parent-child chunks. Answers stream with their source records.

    Agent with live tools

    A GPT-4o tool loop queries stock, sales, orders, forecasts and reports. The voice copilot wraps it with Whisper and TTS.

    Forecasting and monitoring

    Three models compete per product and the best is kept. Rolling z-scores flag sales anomalies and PSI watches for drift.

    Built to be trusted

    Injection and PII guardrails on every input, JWT multi-tenancy, and a CI gate that blocks merges if extraction or guardrail tests regress.

    Helps open-source maintainers work through issues on pandas. It classifies each issue, pulls out the functions, errors and versions it mentions, summarizes long threads, and finds similar resolved issues and docs.

    Customer support triage

    Decision Intelligence Assistant

    Decides which support messages are urgent and drafts a reply. Every query runs through a trained ML classifier, an LLM zero-shot classifier, a RAG answer grounded in similar tickets from Qdrant, and a plain LLM answer, so the approaches can be compared side by side.

    A support message

    HELP!!! I have been trying to get a refund for three days and nobody is responding

    ML urgency classifier, then RAG over Qdrant
    {
  "ml_priority": "urgent",
  "llm_zero_shot": "urgent",
  "retrieved_tickets": 3,
  "rag_answer": "grounded reply with sources",
  "logged": ["latency_ms", "cost_usd"]
}

    Median latency per step, across 21 logged queries

    ML classifier207 ms
    LLM zero-shot classifier1,129 ms
    Plain LLM answer2,833 ms
    RAG answer3,916 ms

    The trained classifier was about five times faster than asking an LLM and costs nothing per call, so it handles routing. The LLM is kept for writing the reply, where a RAG answer cost about $0.0001 per query. Every query, retrieved document, prediction, latency and cost is logged and shown in a React dashboard.

    Natural-language price prediction

    AI Real Estate Agent

    Describe a house in plain English and get a price estimate with an explanation. An LLM turns the description into the features a regression model trained on the Ames housing data expects.

    A property description

    A modern 4-bedroom two-story house with a 2-car garage, built in 2005

    LLM feature extraction, before the price model
    {
  "bedroom_abvgr": 4,
  "house_style": "2Story",
  "garage_cars": 2,
  "year_built": 2005,
  "missing_fields": ["gr_liv_area", "neighborhood"],
  "is_complete": false
}
    1. ExtractThe LLM fills ten fields, like living area, quality, neighborhood and year built, and lists what's missing. It's told never to invent a value.
    2. ValidatePydantic checks types and ranges before anything reaches the model.
    3. PredictA scikit-learn regression model trained on Ames prices produces the estimate.
    4. ExplainA second prompt explains which features drove the price, in plain language.
